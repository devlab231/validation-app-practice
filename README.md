# validation-app-practice

## 概要
COACHTECH 教材 Tutorial 9-6「バリデーション ハンズオン演習」で作成した成果物です。<br>
ユーザー登録フォームを作成しました。FormRequestによる入力値のバリデーションを実装し、入力内容に問題がある場合は日本語のエラーメッセージを表示します。正常に登録できた場合は、登録完了画面へ遷移します。

## 使用技術
- PHP 8.5.12
- Laravel 10.50.3
- FormRequest / バリデーションルール

## 学んだこと
- FormRequestによる入力値のバリデーション
- messages()による日本語エラーメッセージの設定方法
- rules()によるバリデーションルールの設定方法

## 動作確認
GitHubから本プロジェクトを取得し、Laravel Sailを使用して起動することで動作確認できます。<br>
ユーザー登録フォームが表示されることを確認してください。<br>
また、入力内容に応じて日本語のバリデーションエラーが表示され、正常に登録すると登録完了画面に遷移することを確認してください。<br>
※ 実行にはDocker環境および初期設定が必要です。
